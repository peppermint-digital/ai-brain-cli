# Wie diese Doku entsteht

```bash
python3 bauen.py ../ ../markdown
```

Layout in `stil.py`, Schaubilder in `svg.py`, Text in `inhalt*.py`. HTML und
Markdown kommen aus derselben Quelle — sonst laufen sie auseinander, und die
Markdown-Fassung ist die, die niemand nachpflegt.

Dieselben Dateien gehoeren zusaetzlich in Bastians Vault unter
`topics/programmierung/projekte/ai-brain-cli/doku/`.
